# Cloud Native 특징

### 1. 확장성 (Scalability)

클라우드 네이티브에서 **확장성**은 애플리케이션이 **변하는 수요에 맞게 자원을 늘리거나 줄일 수 있는 능력**을 의미합니다.

#### 특징:

- **수평 확장 (Horizontal Scaling)**: 여러 인스턴스를 추가하여 트래픽을 분산시킴. 주로 쿠버네티스에서 사용.
- **수직 확장 (Vertical Scaling)**: 단일 인스턴스에 자원을 더 추가하는 방식.
- **자동 확장 (Auto-scaling)**: 자원의 사용량이나 트래픽 변화에 따라 **자동으로 자원을 조절**하여 효율성을 높임.

### 2. 탄력성 (Elasticity)

**탄력성**은 애플리케이션이 **부하 변화에 따라 자원을 동적으로 조정**하는 능력입니다. 확장성과 비슷하지만, 더 **유동적인 자원 관리**에 초점을 맞춥니다.

#### 특징:

- **수요 기반 조절**: 사용량에 따라 자원을 동적으로 조정.
- **자동 대응**: 예기치 않은 트래픽 증가에 자동으로 대응.
- **비용 효율성**: 자원을 필요할 때만 사용하여 비용을 절감.

### 3. 복원성 (Resilience)

**복원성**은 **장애 발생 시 애플리케이션이 자동으로 복구**하거나, 서비스 중단 없이 운영을 지속하는 능력을 의미합니다.

#### 특징:

- **자동 장애 복구**: 문제가 발생하면 시스템이 자동으로 이를 감지하고 복구.
- **서비스 무중단**: 애플리케이션 일부에 장애가 발생해도 나머지 인스턴스를 통해 서비스를 유지.
- **데이터 복구**: 데이터 복제 및 백업을 통해 신속한 데이터 복구 가능.

### 4. 유연성 (Flexibility)

**유연성**은 애플리케이션이 **다양한 환경에 적응**하고, 변화하는 요구사항에 **쉽게 대응**할 수 있는 능력을 의미합니다.

#### 특징:

- **멀티 클라우드 지원**: 다양한 클라우드 제공업체에서 애플리케이션을 쉽게 운영.
- **다양한 기술 스택 지원**: 마이크로서비스를 통해 여러 언어와 프레임워크 사용 가능.
- **빠른 배포와 롤백**: CI/CD 파이프라인을 통해 **빠른 배포와 즉시 롤백** 가능.
- **애플리케이션 수정 용이성**: 마이크로서비스 기반으로 독립적인 기능 변경이 가능.

---

이 네 가지 특징은 클라우드 네이티브 환경에서 애플리케이션을 **효율적이고 안정적으로 운영**할 수 있도록 해주는 핵심 요소입니다.
